# KTM-LLM 벤치마크 결과 요약

한의사 국가시험(2022~2025년, 총 1,138문항)에 대한 LLM별 정답률입니다.
`stage 5`(한자 병기 + 영어 번역 + CoT + self-consistency 3회), RTX 4090 1장 기준.

## 실행 현황

17개 모델(범용 6 + 중국의학 특화 6 + 서양의학 특화 5) 중 **9개가 성공적으로 완료**되었습니다.
나머지는 게이트 접근 미승인(Llama3.1, Gemma2, Meditron), 원인 미상 서버 기동 실패(HuatuoGPT-o1-8B),
혹은 repo id 미확인/LoRA 전용(Zhongjing 재실패, Qibo, Sunsimiao, ShenNong-TCM)으로 스킵/실패했습니다.
자세한 내역은 `ktm_results/_run_summary.tsv` 참고.

## 참고

- 2025년 데이터는 원래 `subject`가 비어있었는데, `2025한의학_문제_전체.jsonl`과 문제 텍스트를 대조해 276문항 전부 과목을 매칭해 `KTM_data/2025.json`에 채워 넣었습니다.
- 정답률은 self-consistency(3회 다수결) 적용 결과입니다.
- BioMistral-7B, MedLLaMA2-7B는 tokenizer에 chat template이 없어 범용 템플릿(`chat_templates/generic.jinja`)을 강제 적용한 결과입니다 — 각 모델이 원래 학습된 포맷과 다를 수 있어, 정답률이 실제 능력보다 낮게 나왔을 가능성이 있습니다.
